# 3D assets (shipped in-repo, no CDN)

| File | Role |
|------|------|
| `screw.glb` | High-detail screw (helical thread, washer rim, Phillips recess). Runtime builds matching mesh in `js/screwMesh.js` so head color can vary per screw. |
| `panel.glb` | Reference beveled board. Runtime uses ExtrudeGeometry plates with bevel. |
| `cat.glb` … `ufo.glb` | Character cores (code-authored). Game still uses refined RoundedBox procedural cores + anchors from `models.js` for gameplay; GLBs are the asset source of truth for offline/Blender upgrade path. |

Generated by `tools/gen_glb_assets.py` (Blender not available on build box).
